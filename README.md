# Hospital Patient & Treatment Analysis – Power BI

## Project Overview

Hospital Patient & Treatment Analysis is an interactive Power BI dashboard designed to analyze patient visits, treatment costs, medication costs, insurance coverage, emergency visits, patient satisfaction, and hospital operations.

The project demonstrates data preparation, data modeling, DAX calculations, interactive reporting, and business-focused data visualization using Power BI.

## Business Objective

The objective of this dashboard is to provide an overall view of hospital patient and treatment-related data and help identify patterns across:

- Patient visits
- Treatment and medication costs
- Departments
- Insurance providers
- Cities
- Room types
- Emergency visits
- Patient satisfaction
- Visit trends over time

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Synthetic Healthcare Dataset

## Dashboard Analysis

### Patient Visit Analysis

The dashboard analyzes patient visit trends over time and provides insights into patient volume across different periods.

### Cost Analysis

Treatment costs, medication costs, and room charges are analyzed across cities, departments, room types, and insurance providers.

### Insurance Analysis

Patient distribution is analyzed across different insurance providers to understand the contribution of each provider.

### Emergency Visit Analysis

The dashboard tracks emergency visits and provides the overall emergency visit percentage.

### Patient Satisfaction

Average patient satisfaction score is used to understand the overall patient experience.

### Department Analysis

Treatment costs are analyzed across different departments and insurance providers to identify variations in treatment-related expenses.

## Data Privacy

This project uses a synthetic healthcare dataset created for portfolio and demonstration purposes.

It does not contain real patient, hospital, insurance, or organization data. The dashboard is intended only to demonstrate Power BI, DAX, data modeling, visualization, and analytical skills.
